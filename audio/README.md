# ホームの音楽（時間帯ごと）

ここに置いた曲を、ホーム画面で時間帯に合わせて流します（練習の画面では流しません）。

| ファイル名 | 流れる時間帯 | 雰囲気の例 |
|---|---|---|
| `bgm-morning.mp3` | 5:00〜10:59 | 軽いジャズ |
| `bgm-day.mp3` | 11:00〜16:59 | 明るく軽快 |
| `bgm-evening.mp3` | 17:00〜20:59 | 落ち着いた |
| `bgm-night.mp3` | 21:00〜4:59 | しっとり |

- 置いたファイルの名前を、index.html の `BGM_TRACKS` に書くと有効になる（空のままなら音楽もボタンも出ない）。
- 一部の時間帯だけでもよい（ない時間帯は、近い時間帯の曲を流す）。
- mp3（128kbps 程度、1曲 2〜4MB まで）を目安に。曲の終わりから頭へ自然につながる曲だと聞きやすい。
- 商用利用できる曲だけを使い、配布元の利用規約（クレジット表記の要否など）を確認すること。
