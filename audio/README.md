# ホームの音楽

ここに置いた曲を、ホーム画面で順番に流します（時間帯では分けません。練習の画面では流しません）。

| ファイル名 | 長さ |
|---|---|
| `wooly-days-cafe.mp3` | 2分32秒 |
| `chill-morning.mp3` | 58秒 |
| `her-smile.mp3` | 2分1秒 |
| `bgm-loop-1.mp3` | 1分30秒 |
| `bgm-loop-2.mp3` | 2分45秒 |
| `calm-night.mp3` | 1分10秒 |
| `night-signal.mp3` | 1分20秒 |

- 流す曲は、index.html の `BGM_TRACKS`（ファイル名の配列）に書く。空にすると音楽もボタンも出ない。
- 流す順番は毎回シャッフルし、7曲を1周したら並べ直す。同じ曲は続けて流さない。
- 曲ごとの音量の差をなくすため、音量（ラウドネス）を -18 LUFS にそろえ、mp3 128kbps にしてある。
  - 曲を足すときも同じようにそろえる。例：`ffmpeg -i 元の曲.mp3 -af loudnorm=I=-18:TP=-1.5:LRA=11 -ar 44100 -b:a 128k 新しい名前.mp3`
- 商用利用できる曲だけを使い、配布元の利用規約（クレジット表記の要否など）を確認すること。
